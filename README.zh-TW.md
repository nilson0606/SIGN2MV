# SIGN2MV

[English](README.md)

唱錄、AI 翻唱、歌詞 MV 合在一個在 Windows 本機執行的程式裡。

- **歌曲庫**：每首歌只要匯入一次（YouTube 或檔案），分離好的分軌所有工作區共用。
- **唱錄**：跟著音高提示唱、評分，錄整首或分段，錄音後處理。
- **AI 翻唱**：RVC 音色轉換（Applio）、多版本、快速混音、人聲分段處理、男女對唱、訓練自己的音色模型。
- **MV**：用音檔直接出片（快速 MV），或用照片和歌詞做 1080p 60fps 歌詞 MV（Whisper 對齊、卡拉 OK 變色）。

全部在這台電腦上執行，不會上傳任何東西。

## 快速開始（Windows 10／11）

1. 在本頁按綠色的 **Code → Download ZIP**，解壓縮到路徑只有英文和數字的資料夾，例如 `D:\SIGN2MV`
   （把 `SIGN2MV-main` 改名）。電腦不需要先裝任何東西。
2. 雙擊 `install.bat`。它會把 Python、AI 程式和模型下載到這個資料夾裡（第一次約 10 GB）；中斷了就再執行一次。
   如果 Windows 跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
3. 雙擊 `start.bat`，程式會用獨立視窗開在 `http://127.0.0.1:9700`。
4. 在程式裡：**歌曲庫** → 新增歌曲 → 從 YouTube 或檔案匯入，接著就可以唱錄、做 AI 翻唱或做 MV。

程式不附任何歌曲，也不附音色模型：歌曲由你自己匯入；音色模型用自己的聲音訓練，或匯入你有權使用的模型。

Python、模型、快取、暫存檔全部裝在這個資料夾裡，不會裝到 C 槽。

完整手冊（含一步一步的新手入門）在 `web/manual/`（英文為主版本，另有繁體中文翻譯），程式上方的
**操作手冊 ↗** 就能打開。有問題請到 [GitHub Issues](https://github.com/nilson0606/SIGN2MV/issues) 回報。

## 系統需求與限制

- Windows 10 或 11（64 位元）。目前不支援 macOS 和 Linux。
- 第一次安裝約下載 10 GB，全部放在程式資料夾裡；之後的歌曲與作品也放在同一個資料夾，請多留空間。
- AI 工作（分離、音色轉換、訓練、Whisper）有 NVIDIA 顯示卡時用 CUDA，沒有就用 CPU（慢很多）。開發時用的是
  RTX 4060 Laptop（8 GB）。
- MV 編碼依序試 NVIDIA（NVENC，驅動 570 版以上）、AMD（AMF）、Intel（Quick Sync）顯示卡，都不行才用 CPU；
  安裝程式會寫出哪一種可以用。
- 唱錄需要麥克風（建議戴耳機）。

## 使用規範

只匯入你有權使用的歌曲與錄音。YouTube 匯入使用 yt-dlp，請遵守你所在地區的 YouTube 規範。只對你有權使用的聲音
使用音色模型，也不要把轉換後的聲音當成別人真的唱的。
