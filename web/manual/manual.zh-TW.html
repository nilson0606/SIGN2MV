SIGN2MV

唱錄、AI 翻唱、歌詞 MV 合在一個程式裡。本手冊是英文版（主版本）的翻譯。第一次使用請從「2. 新手入門」開始。

1. 概觀

SIGN2MV 把唱歌錄音、AI 翻唱和歌詞 MV 放在同一個程式、同一個歌曲庫裡：

  • 歌曲庫：每首歌只要匯入一次（YouTube 或檔案）。分離出來的分軌也只算一次，所有工作區共用。
  • 唱錄：跟著音高提示唱、評分，錄整首或分段，後製後儲存。
  • AI 翻唱：用 RVC 音色模型轉換歌曲的人聲、混音、保留多個版本、修正局部段落，也能訓練自己的音色模型。
  • MV：用音檔直接出片（快速 MV），或用照片和歌詞做 1080p 60fps 的歌詞 MV，有 Whisper 歌詞對齊與卡拉 OK 變色。音檔可以是原曲、任何一次唱錄，或任何一個翻唱版本。

全部在這台電腦上執行，不會上傳任何東西。吃重的工作（分離、音色轉換、Whisper、影片渲染、訓練）在顯示卡上一次跑一個；較輕的工作可以同時進行。

程式不附任何歌曲，也不附音色模型。歌曲由你自己匯入；音色模型要自己訓練，或匯入你有權使用的模型（第 8 章）。

2. 新手入門（一步一步）

第一次使用，照下面的順序做。每一步都寫了「做什麼」和「成功時看到什麼」；看到成功的樣子再做下一步。

步驟 1：確認電腦

  • Windows 10 或 11（64 位元）。目前不支援 macOS 和 Linux。
  • 網路：第一次安裝要下載約 10 GB。之後匯入 YouTube 歌曲也需要網路。
  • 硬碟：除了這 10 GB，之後的歌曲、分軌、錄音和影片也會放在同一個資料夾，請多留空間。
  • 建議有 NVIDIA 顯示卡。沒有也能用，只是分離、翻唱、訓練會慢很多。
  • 要唱錄的話：麥克風和耳機。

步驟 2：下載程式

  1. 用瀏覽器打開這個下載連結：SIGN2MV.zip（最新版）。它永遠是最新發布的版本；各版本列在 Releases。

成功：瀏覽器的下載清單出現 SIGN2MV.zip。

步驟 3：解壓縮到英文路徑

  1. 在檔案總管找到 SIGN2MV.zip，按右鍵 →「內容」。如果視窗最下面有 解除封鎖 的勾選框，把它勾起來，按「確定」。（沒有這個勾選框就跳過。）
  2. 再按右鍵 →「解壓縮全部…」，把目的地改成 D:\（或其他磁碟），按「解壓縮」。ZIP 裡已經包了一層 SIGN2MV 資料夾，所以會得到 D:\SIGN2MV。

成功：打開 D:\SIGN2MV，裡面直接看得到 install.bat、start.bat 和 MANUAL.html（雙擊它就能打開這份手冊，不用先安裝）。如果看到的是另一層 SIGN2MV 資料夾（例如 D:\SIGN2MV\SIGN2MV），代表多包了一層，把裡面的東西搬上來。

資料夾的完整路徑只用英文字母和數字，不要有中文（例如 D:\SIGN2MV 可以，D:\我的程式\SIGN2MV 不行）。路徑有中文時，音色模型的 index 會讀不到。

步驟 4：安裝

  1. 在 D:\SIGN2MV 裡雙擊 install.bat。會開一個黑色視窗開始下載和安裝。
  2. 如果 Windows 跳出藍色的「Windows 已保護您的電腦」，按「其他資訊」，再按「仍要執行」。
  3. 一開始（還沒開始下載前）會先問 Download the Sucial model? [y/N]：這是男女對唱用的選用模型，限非商業使用。接受這個條件就輸入 y 按 Enter；不需要就直接按 Enter（男女對唱改用另一個模型，一樣能用）。
  4. 等它跑完。第一次會花不少時間（看網路速度）。中途斷掉的話，再雙擊一次 install.bat，做過的步驟會跳過。

成功：黑色視窗最後出現 Done. Double-click start.bat to open SIGN2MV.，按任意鍵關掉視窗。

步驟 5：開啟程式

  1. 雙擊 start.bat。會開一個黑色主控台視窗（伺服器），接著跳出 SIGN2MV 視窗。
  2. 使用期間黑色視窗要一直開著（可以縮小）。

成功：SIGN2MV 視窗打開在「首頁」；「系統狀態」裡的 安裝 顯示「已完成」，運算裝置 顯示你的顯示卡（沒有 NVIDIA 顯示卡時顯示 CPU）。介面語言跟著 Windows（繁體中文以外的 Windows 會是英文），上方可以切換。

步驟 6：匯入第一首歌

  1. 按上方的 歌曲庫。
  2. 在左上方的框輸入歌名，按 新增歌曲。
  3. 新歌會被選起來；在右邊「匯入音樂」貼上 YouTube 網址，按 從 YouTube 匯入。（或把電腦裡的音檔／影片拖到虛線框裡。）

成功：顯示「匯入完成」，歌曲下方出現收合的「▸ 原曲」（點開就有原曲播放器）和三個按鈕：唱錄這首、製作 MV、AI 翻唱。

步驟 7：唱一次並評分

  1. 按 唱錄這首，會切到唱錄頁並載入這首歌。
  2. 第一次唱這首歌時，頁面會請你按 準備歌曲基準。按下去等它做完（分離人聲並抓出音高，第一次要幾分鐘），狀態顯示就緒才繼續。
  3. 戴上耳機。按 開啟麥克風，瀏覽器問麥克風權限時選允許。對著麥克風說話，「收音音量」要有反應。
  4. 按 從頭開始唱且評分，影片從頭播放，跟著唱。
  5. 唱完（或想停時）按 結束並結算。

成功：出現總分和音準、進拍、完整度三項分數；錄音放在「整首錄音 · 待確認」，可以試聽，滿意就按 存到錄音後處理。

分數偏低、或音高線總是比原唱晚一點，多半是收音延遲不對（預設 400 ms，每台電腦不一樣）。可以用唱錄頁的「五音延遲測試」量，或用「重新評分」換幾個延遲值試（第 6 章），不必重唱。

步驟 8：準備一個音色模型

AI 翻唱需要音色模型，程式不附任何模型。按上方的 AI 翻唱，在右側的 音色模型 擇一：

  • 訓練自己的聲音：準備合計約 10 分鐘以上、乾淨的清唱或說話錄音，在「訓練音色模型」加入檔案，按 🚀 開始訓練。訓練要用顯示卡跑一段時間。
  • 匯入現成的模型：有你有權使用的 RVC 模型（.pth，通常還有 .index），用 從資料夾匯入 或 上傳模型檔。

成功：模型名稱出現在模型清單，左邊「音色模型」選單也選得到它。

步驟 9：做第一個翻唱

  1. 在 AI 翻唱頁上方選歌。
  2. 左邊「音色模型」選你的模型；「變調」照需要設定（女聲歌給男聲約 −12，男聲歌給女聲約 +12，同性別通常 0）。
  3. 按 🎤 製作翻唱（新版本）。第一次會先分離這首歌，進度顯示在按鈕下方。

成功：右邊「版本」出現 #1，可以直接播放。

步驟 10：做第一支 MV

  1. 在版本 #1 上按 快速 MV（會切到 MV 頁的「快速 MV」分頁，音檔已選好）。
  2. 確認標題和演唱者，按 產生快速 MV。

成功：下方清單出現這支影片，可以播放、下載 MP4。要用照片和歌詞做完整 MV，看第 9 章。

步驟 11：關閉程式

按右上角的 全部關閉。成功：SIGN2MV 視窗顯示已關閉，黑色主控台視窗在幾秒內自己消失。下次使用從步驟 5 開始。

3. 安裝細節

步驟見第 2 章。這裡補充安裝程式做了什麼：

  • 電腦不需要先裝 Python 或任何工具。install.bat 會自己下載 Python 管理工具 uv（核對驗證碼）、Python 3.12、各環境需要的套件、ffmpeg、Applio（音色轉換）和 AI 模型。
  • 全部裝在 SIGN2MV 資料夾裡（runtime\、models\），快取和暫存檔也是，不會裝到 C 槽。安裝前後 C 槽的空間變化會顯示在首頁。
  • 安裝中斷（網路斷線、磁碟滿）時，再執行一次 install.bat 即可，已完成的步驟會跳過。記錄檔在 logs\install.log。首頁的「安裝」與檢查清單會顯示哪些已就緒。
  • 有 NVIDIA 顯示卡會自動使用；沒有也能用 CPU 執行，只是比較慢（用 CPU 訓練非常慢）。
  • MV 編碼依序試 NVIDIA（NVENC，驅動要 570 版以上）、AMD、Intel 顯示卡，都不行才用 CPU；安裝時會在 logs\install.log 寫出哪一種可以用。
  • ffmpeg 固定用同一個版本，下載後會核對檔案驗證碼，每台電腦裝到的都一樣。
  • 安裝最後會把各環境的 Python 程式先編譯好，之後每次分離、翻唱、Whisper 啟動都比較快。

更新到新版

更新只要把新版的檔案覆蓋到原本的資料夾，你的歌曲、錄音、音色模型和設定都不會被動到（library、models、runtime、config 不在 ZIP 裡）。

  1. 在 SIGN2MV 右上角按 全部關閉，等視窗關掉。
  2. 下載 SIGN2MV.zip（最新版），在 ZIP 上按右鍵 →「內容」→ 勾「解除封鎖」→「確定」（沒有這個勾選框就略過）。首頁的 檢查更新 有新版時也會附這個連結。
  3. 解壓縮到任何暫存位置（例如「下載」資料夾），會得到 SIGN2MV 資料夾。
  4. 打開這個新的 SIGN2MV，全選（Ctrl + A）、複製，貼到原本的安裝資料夾（放 start.bat 的那個），跳出詢問時選「取代目的地中的檔案」。
  5. 雙擊 start.bat，在首頁「系統狀態」下面按 檢查更新，顯示「已是最新版」就完成了。

想知道有沒有新版，隨時都可以按 檢查更新：它會告訴你是不是最新版，有新版時附上下載連結（只查詢，不會自動下載或覆蓋）。

只有 CHANGELOG.md 寫要重跑 install.bat 時才需要重跑；不確定時跑一次也沒有壞處，已經裝好的部分會略過。

4. 開啟與關閉

  1. 雙擊 start.bat。會開一個主控台視窗（伺服器）和 SIGN2MV 視窗（用 Windows 內建的 Edge 以獨立視窗開啟，網址是 http://127.0.0.1:9700）。使用期間請保持主控台視窗開著。
  2. 結束時按右上角的 全部關閉。如果有工作在跑，或某個工作區正在忙（錄音、轉換、渲染），SIGN2MV 會列出來，問你要不要取消。關閉後主控台視窗會在幾秒內自己消失。

介面語言跟著 Windows：繁體中文的 Windows（台灣、香港、澳門）顯示中文，其他語言的 Windows（包括簡體中文）顯示英文；可用上方的語言選單切換。上方的 操作手冊 ↗ 會開啟本頁。程式只接受這台電腦自己的連線，區域網路上的其他電腦連不進來。

5. 歌曲庫

  1. 打開 歌曲庫，在左上方輸入歌名，按 新增歌曲。
  2. 匯入音樂：貼上 YouTube 網址（或按 📋 從剪貼簿貼上），按 從 YouTube 匯入（也會下載影片，最高 1080p）。網址一貼上就會出現預覽卡：縮圖、標題、長度、影片 ID，可以按 前往原站 或 ▶ 預覽 先看再匯入。也可以選一個音檔／影片按 上傳本機檔案，或直接把檔案拖到虛線框裡（放開就開始上傳，有進度條；最大 2 GB、15 分鐘）。原始檔案不會被改動。
  3. 匯入完成後，歌曲會顯示收合的「▸ 原曲」（點開就有原曲播放器）和三個按鈕：唱錄這首、製作 MV、AI 翻唱。

「原曲」裡的影片下方有 下載 MP3：把這首歌的原曲音訊轉成 192 kbps MP3 下載（從無損的原曲音檔轉，只壓一次；4 分鐘的歌約幾秒）。影片右下角 ⋮ 選單裡的「下載」是瀏覽器內建的，下載的是 MP4 影片。

音軌平移的用途：讓影片裡的字幕比歌聲早一點出現，K 歌和錄音時比較好跟。想讓字幕早一點，就填＋（聲音往後移）；例如填 +1.00，字幕會比歌聲早 1 秒出現。

音軌平移（在「原曲」的「下載 MP3」下方）：畫面和聲音沒對齊時（例如嘴型或字幕比聲音早、晚），可以把聲音平移 −2.00～＋2.00 秒，每格 0.01 秒，畫面不動、長度不變。欄位的數字是相對「原始匯入的音檔」的總平移：還沒平移過的歌，欄位預設填 +1.00（字幕比歌聲早 1 秒）；平移過的歌顯示目前的值。0 就是原始對齊。

  • 只能用在剛匯入的歌：還沒分軌、唱錄、翻唱或做 MV 的歌才能平移，因為那些結果都是照目前的時間軸做的。只要做過其中任何一樣，欄位和按鈕就會變灰，下方會寫原因。
  • ＋：聲音晚一點出來，開頭補靜音、結尾切掉同樣長度。−：聲音早一點出來，開頭切掉、結尾補靜音。
  • 填好秒數，按 ▶ 試播：影片會靜音播放，聲音照你設的秒數錯開，邊聽邊調都可以。試播的音量用旁邊的 試播音量 調；試播時影片會一直保持靜音，就算按了影片自己的音量鈕也會自動切回靜音（不然會兩份聲音疊在一起），並把你調的大小帶到試播音量（第一次按要先載入音檔，4 分鐘的歌約 1～2 秒。試播已把音效卡的輸出延遲算進去；套用後的結果則是逐點精確的）。也可以先把影片拖到有嘴型或字幕的地方再試播。
  • 試播過、而且跟目前不同的秒數，套用 才會亮起來（黃色發光）；改了秒數沒試播，就要再試播一次。
  • 按 套用 會跳出確認視窗。按確定後，原本的音檔和影片會刪除，無法復原；被切掉的那一端聲音也會永久消失。用檔案匯入的歌，source 裡保存的原始檔也會一起刪除。新的音檔和影片完整做好才刪舊的，中途失敗會保留原檔。4 分鐘的歌大約幾秒完成。
  • 成功：畫面出現「音軌已平移 ＋0.30 秒」之類的提示，下方顯示「目前累計已平移 …秒」。還沒分軌前可以再改，例如從 ＋1.20 改回 0 就是回到原始對齊；但之前被切掉的那一端補不回來，會變成靜音。
  • 如果在你按套用之前，這首歌剛好被分軌或做了其他處理，套用會被拒絕、檔案不動，欄位變灰並寫出原因。

分軌與升降 Key

在「分軌與升降 Key」可以準備並試聽分離後的音軌：選分離模型（Demucs、BS-RoFormer、Mel-RoFormer Kim），可選伴奏二次分離、拆主唱／和聲，以及升降 Key。分離結果每首歌只存一份，任何工作區需要同樣的分軌都會直接沿用。

已存的分軌（在「準備分軌」按鈕下方）列出這首歌存著的每一份分離和升降 Key，以樹狀排列：主唱／和聲會排在它所來自的那份分離底下。每一列顯示音軌、大小、日期，以及哪些翻唱版本或唱錄準備正在用它。按 刪除 會刪掉這份和由它產生的全部。不會壞掉：用到它的地方下次需要時會自動重新分離（要多等幾分鐘）。這首歌有工作在跑時要等它完成才能刪。

換來源：已有原曲的歌，最上面會有收合的「▸ 重新匯入（換來源）」，點開就能用新的網址或檔案取代原曲。新的原曲完整到位後才會刪掉舊的；中途失敗或程式被關掉，會還原舊的原曲。換過來源後，唱錄的舊基準會標「來源已更換，載入時會重新建立」，載入時自動重建。

點區塊標題（原曲、分軌與升降 Key、已存的分軌、儲存空間）可以收合或展開，頁面會記住你開著哪些。收起來時標題旁仍顯示一行摘要。在「已存的分軌」裡，按 ▸ 底下 N 份 可以展開或收起由那一份產生的副本。

儲存空間

歌曲清單會顯示每首歌佔多少空間，下方是整個歌曲庫的總量和硬碟剩餘空間。每首歌的「儲存空間」區塊把大小分成原曲、分軌與升降 Key、AI 翻唱成品、翻唱暫存、唱錄、MV 專案和其他，並寫出各自在哪裡清理：

  • 分軌與升降 Key：在「已存的分軌」逐份刪除。
  • AI 翻唱成品和暫存：到 AI 翻唱頁刪版本；只有這些版本用到的暫存會一起清掉。版本上方的 🧹 清理這首歌的中間檔 會先列出沒在用的 AI 轉換人聲、分段處理片段、升降 Key 試聽檔和大小，確認後才刪。
  • 唱錄：到唱錄頁刪錄音和準備好的歌曲。
  • MV：到 MV 頁刪專案。

改名 改歌名。刪除 會在確認後刪除這首歌和它產生的所有東西（分軌、錄音、翻唱、MV）。

成品資料夾

歌曲庫裡每首歌的資料夾是用編號命名的，在檔案總管不好找。SIGN2MV 會在歌曲庫裡維護一個成品資料夾 Finished（資料夾名稱固定用英文）：每首歌一個資料夾，用歌名命名，裡面是捷徑，點兩下就開。檔案不會複製，不多佔空間。

  • 翻唱版本：翻唱 #1 MyVoice -12 · Key -2
  • 唱錄後製存的版本：唱錄 10-31 09：05
  • 快速 MV：快速MV 錄音室 1080p · 翻唱 #1 · 10-31 09：20
  • 完整 MV（算圖完成後）：MV 專案標題

翻唱名稱裡的變調或 Key 是 0 時，那一段省略，例如 翻唱 #2 MyVoice。時間用全形冒號（09：05），因為 Windows 檔名不能有「:」。兩首歌同名時，資料夾後面加匯入日期，例如 童話（10-29 匯入）；同一天匯入的再加時間。同一首歌裡名稱還是重複的，後面自動加 (2)、(3)。

改歌名，資料夾跟著改名。刪掉版本、MV 或整首歌，對應的捷徑也會刪掉；只會刪 SIGN2MV 自己建的捷徑，你自己放進去的檔案不會動（資料夾裡還有你的檔案時，資料夾會留著）。手動刪掉某個捷徑，下次有變動時會再建回來；不要的成品請在 SIGN2MV 裡刪。

按歌曲庫的 📂 成品資料夾 開整個資料夾，或歌曲詳情的 📂 成品 直接開這首歌的資料夾（Windows）。

6. 唱錄

歌曲從歌曲庫選：在唱錄頁上方的 歌曲（SIGN2MV 歌曲庫） 選歌，按 載入歌曲（或在歌曲庫按 唱錄這首）。已經做過歌唱基準的升降 Key 會在選單裡另外列出（例如「童話 · 降 4 Key」）；有基準就直接載入，沒有的話頁面會請你按 準備歌曲基準，Key 也會先幫你選好。每個控制項的詳細說明在唱錄頁上方的 說明 ↗。

準備歌曲

  • Key：播放器下方可選原調或 −12～＋12 半音（速度不變）。歌曲已載入時，選好後按 建立／載入此 Key。
    Key 下方的 人聲保留原唱音色（預設不勾）：勾了之後，原唱人聲升降 Key 時保留歌手本人的音色（共振峰），聽起來比較像原唱本人在那個 Key 唱，但可能多一點雜音；伴奏照舊。勾與不勾是兩個不同的 Key 版本，各自保存，可以來回切換比較。2026-11-07 用舊做法做的版本，清單會標「保留原唱音色（舊做法）」：還能載入，錄過的錄音也能照常後處理，但不能再重建；想要新做法的音色，請另外建立新的版本。
  • 按 準備歌曲基準，等到狀態顯示就緒。預設是完整歌曲（最長 15 分鐘）、Demucs 分離、RMVPE 音高。「分離與音高設定」可以改分析範圍（先試前 15／30／60 秒，這一小段另外分離，不會動到整首的分軌）、分離模型、主唱／和音分離。
  • 取消勾選 保留分離音軌 時只留音高基準，這次做出來的分軌會在完成後刪掉（之後要試聽或「只有伴樂」帶唱時得重建）。

收音與延遲

  • 收音方式：預設 瀏覽器收音。如果一開麥克風伴奏就變小聲，改選 本機相容收音（由這台電腦的 Python 收音，第一次 Windows 會問 Python 的麥克風權限）。
  • 按 開啟麥克風，確認「收音音量」有反應。請戴耳機，避免原唱從喇叭漏進麥克風。
  • 收音延遲（「看節拍，調延遲」區）：預設 400 ms，表示你的歌聲比歌曲晚 400 ms 到。每台電腦、每支麥克風不一樣；可以用 五音延遲測試 量，量完按 套用建議補償。

唱整首並評分

  1. 評分設定：音域比對（預設允許高／低八度，適合跟原唱不同音域的人）、評分範圍（預設只比已演唱範圍）、評分難度（標準／嚴格／寬鬆）。
  2. 帶唱選 原唱＋伴樂（預設）或 只有伴樂／和音。主唱／和音分離的版本，預設項目顯示為 原唱＋和音＋伴樂，並多一項 原唱＋伴樂（不含和音）（只播主唱和伴奏）。預設以外的兩項會把影片靜音、改播分離音軌。錄音內容選 歌唱者、歌唱者＋配樂／和音（預設）或 不保存錄音。
  3. 耳機單聲道（預設不勾，維持立體聲）：勾了之後，帶唱的聲音左右耳一樣，適合只戴一邊耳機、露出一耳唱（比較不會悶住自己的聲音）；分段錄音也適用。拿下的那邊耳機別對著麥克風，免得伴奏被錄進去。選擇會記住。
  4. 耳機聲音：左耳／右耳（預設都勾）：取消勾選就是那一耳靜音。只戴一邊時把拿下的那邊靜音，就完全不會漏音進麥克風；也可以用來比較戴左耳還是右耳好唱。每次打開唱錄頁都會回到兩耳都有聲音。搭配「耳機單聲道」，戴著的那一耳會聽到完整的左右聲道。旁邊的「送出音量」顯示唱錄頁實際送到左右耳的聲音。
    Windows 的「單聲道音訊」（設定 → 協助工具 → 音訊）開著時，Windows 會在所有程式之後把左右混在一起，左右耳開關和「耳機單聲道」就沒有作用；這時開關下方會出現黃色提醒。要用的話按 Win＋A → 協助工具 → 關閉「單聲道音訊」，唱完再打開。按「全部關閉」時，如果它和開啟 SIGN2MV 時不一樣，也會提醒你改回來。
  5. 按 從頭開始唱且評分。唱完按 結束並結算（影片播完也會自動結算）。
  6. 分數：總分由音準 60%、進拍 25%、完整度 15% 組成。錄音放在 整首錄音 · 待確認：可以試聽、下載、刪除，滿意按 存到錄音後處理。

重新評分（不用重唱）

結束並結算 旁邊有 評分對象、重新評分 和 評分延遲：

  • 評分對象可以選：剛唱完的這次、這首歌這個 Key 已存的錄音（整首錄音和分段合成都有），或這首歌這個 Key 的 AI 翻唱版本。
  • 改評分延遲再按 重新評分，就能看到同一次演唱在不同延遲下的分數，用來找出你的電腦適合的延遲。每次重新評分都會另存一筆分數紀錄。
  • 改了評分延遲後，這首歌接下來的演唱會暫時用新值；換歌或重新整理後回到「收音延遲」的設定。
  • 已存的錄音第一次重新評分，會先用 RMVPE 分析幾秒，結果存回那筆錄音。AI 翻唱版本的評分延遲從 0 開始，版本自己的變調（例如 −12）會在評分時補回，分數代表轉換有沒有保住旋律。
  • 音域比對的設定跟著錄音保存；舊的分段合成沒有存到這個設定時，用畫面上目前的「音域比對」。

測試原唱分數

🧪 測試原唱分數 用分離出來的原唱人聲代替麥克風，跑一次跟你演唱完全一樣的評分與錄音流程，用來看這首歌的基準與評分在原唱身上算出幾分，判斷分數低是基準的問題還是演唱的問題。原唱少了「喇叭放出來、聽到再跟唱」那段延遲，所以用 原唱延後（預設 200 ms）讓它晚一點進來。這次錄音會標成「原唱測試」，不會改動你的收音延遲。

分段錄音

  1. 按亮色的 開啟錄音模式。播放時在想切開的地方按 在此分段，把歌切成幾段（可以復原、合併、微調分界）。
  2. 選一段，按 錄這一段：會從段落前一點開始帶唱，唱到尾音餘量後自動保存（也可以按 停止／保存本段）。每段想錄幾次就錄幾次。
  3. 每段存好後，麥克風會自動關閉；下次按 錄這一段 會自動重新開啟。存檔期間（顯示「正在保存本段錄音…」）不能錄下一段。
  4. 每段選一個要用的版本，按 試合完整一版 組成整首。「試合內容」選 人聲＋伴樂／和音（預設）或 純人聲；主唱／和音版本另有 人聲＋伴樂（不加和音），成品不放和音。還沒錄的範圍可以勾 允許未錄範圍保留靜音；也可以用 新增原唱區間 讓某些範圍用原唱。
  5. 滿意按 存到錄音後處理，或下載 WAV。分段合成也可以重新評分。

錄音後處理

音量、歌聲延時校正、柔化、EQ、壓縮、殘響／延遲、降噪、齒音與呼吸聲降低、音準修正、剪輯與淡入淡出；同一句做 A/B 比較；重新渲染（原始人聲永遠保留）。錄音重新評分 可以用不同延遲和難度重算已保存的錄音。完成的錄音可以按 製作 MV：錄音會存成這首歌的 MV 音檔，並直接打開 MV 工作區。

其他

不計分區間遮罩（在「分離與音高設定」裡）可以讓誤判的段落（例如被當成人聲的間奏樂器）不計入分數。

在清單裡刪除準備好的歌，也會刪掉只有它在用的分軌，並告訴你釋放了多少空間。

7. AI 翻唱

打開 AI 翻唱（或在歌曲庫的歌曲上按 AI 翻唱），在上方選歌。左邊是設定，右邊是版本、音色模型與訓練。

製作翻唱

  1. 音色模型：選一個模型（有保留訓練中間版本的，也可以選某一輪）。新的歌會預設上次用過的模型。清單是空的話，先匯入或訓練模型（第 8 章）。
  2. 變調：人聲的半音數（女轉男約 −12、男轉女約 +12）。「0（原調）」「−12（女轉男）」「+12（男轉女）」按一下就設好。
  3. 整首升降 Key：−8 到 +8。伴奏和原唱和聲用 Rubber Band 升降（速度不變），人聲轉換時一起加上同樣的變調（和聲也轉換時，和聲同樣在轉換時加上）。「▶ 試聽升降後」播放升降後的原曲；按原調會從同一秒接著播，可以來回比較。「歸零」回到原 Key。沒有 Rubber Band 時頁面會說明，Key 不能調。
  4. 可選 RVC 微調：子音／呼吸保護（0.33）、特徵檢索比例（0.75）、音量包絡（0＝跟著原唱的大小聲）、音高偵測（rmvpe）、音高自動修正、降噪。
  5. 可選 分離與和聲：分離模型；人聲處理＝拆出主唱轉換、保留原唱和聲（預設），或整條人聲一起轉，或三人以上和聲時拆兩次；拆主唱模型（aufr33 / viperx，或已下載的 becruily；沒下載時頁面會寫出 1.7 GB 檔案要放哪裡和下載網址）；伴奏單次或二次分離。這一區會顯示哪些分離模型可以用。拆出主唱時，「混音」區的 和聲混進成品 決定成品要不要加回和聲，改了按快速混音就好。下面的 和聲也轉成我的聲音（預設關）：很多歌的和聲是主唱自己唱的，勾了以後和聲也用同一個模型、同樣的變調轉換（多花差不多主唱轉換的時間，之後快速混音沿用）；好幾個人同時唱不同音的和聲可能有雜音，請試聽比較。版本名稱會多「Backing VC」。
  6. 混音：轉換後人聲音量（95%）與伴奏音量（85%），有「人聲突出」「標準黃金比」「伴奏為主」三個預設。每一組微調都有 恢復預設。
  7. 確認按鈕上方的 這次會用（模型、變調＋Key、伴奏 Key、男女兩邊）。勾「這次重新分離」會這一次不沿用已分好的分軌。
  8. 按 🎤 製作翻唱（新版本）。進度顯示在按鈕下方和工作佇列；日誌 打開執行紀錄，取消 停止。做完後「翻唱完成」框上也有 日誌，可以回頭看這次每一步花多久。視窗在背景時，分頁標題會提醒你完成了。

分離與轉換結果都會沿用。同樣設定再做一次不會重算；只改混音很快。每首歌的設定各自保存；第一次翻唱一首新歌時，設定全部是預設值，只有聲音模型沿用上一次翻唱用的。

版本

每做一次就是一個版本（#1、#2…），各有自己的 MP3。版本上的按鈕：

載入設定把這個版本的設定帶回左側。
🎛️ 快速混音把左側的混音、人聲分段處理、分段音量、和聲選擇、男女音量套用到這個版本並取代它的音檔。模型、變調、Key、分離維持原樣。
另存新版本同上，但保留舊版本、另外新增一個。
快速 MV用這個版本直接出片（標題＋跳動頻譜），打開 MV 頁的快速 MV 分頁。
🎬 製作 MV用這個版本當音檔，打開完整 MV 工作區。
下載／分軌試聽下載 MP3；試聽這個版本用到的原曲、分軌和轉換後人聲。
改名／刪除刪除也會刪掉這個版本的音檔；沒有其他版本使用的暫存檔會一起清掉。如果有 MV 專案用它當音樂，確認視窗會寫出專案名稱（已輸出的 MV 影片會保留）。
📂在檔案總管顯示這個 MP3。
🎬 立即觀看快速 MV／完整 MV用這個版本做過 MV 時才會出現，直接在這裡播放。

勾選多個版本可以一次刪除（「全選」「刪除勾選」）。每個版本會顯示檔案格式和大小。播放版本時，清單上方的線條會顯示即時頻譜。📚 所有歌的翻唱成品 把每首歌的版本列在一起，可以搜尋；按 開啟這首 切換過去。

每個版本也會出現在這首歌的 MV 音檔清單。

人聲分段處理

播放任一版本或原曲，按 ⏱ 把播放時間帶入「起點」／「終點」（也可以輸入 1:23.4 或 83.4）。清單裡每一段都有 ▶ 可從這段前一點開始試聽，也可以編輯或刪除；收合標題會顯示共幾段。每一段可以選：

  • 改用原唱：這段用原唱（音量自動對齊），例如這段是別人唱的。
  • 靜音：這段不要有人聲。
  • 重轉：這段用別的模型、變調或參數（含音高自動修正、降噪）重新轉換（前後多取 1 秒當上下文）。也可以讓這段用自己的分離模型、拆主唱設定與拆主唱模型重新分離，這時這段的伴奏也會一起換掉。
  • 換成外部音檔：上傳自己錄的或別的版本。可以只取代轉換後人聲，或在檔案已含伴奏時取代整段混音。檔案的 0 秒會對齊「起點＋位移」；沒填終點時，這段長度就是檔案長度。外部人聲也可以轉成模型音色。

分段音量

只調整某兩個時間點之間的轉換後人聲、伴奏或和聲音量（0–200%，邊界 80 毫秒平滑）。▶ 試聽這段，✏️ 把這段帶回欄位修改。

男女對唱

勾選「啟用男女對唱」：人聲會拆成男聲和女聲（aufr33 模型；有安裝的話也可用 Sucial）。每一邊有自己的模型、變調、音量與微調，也可以保留原唱。之後只改兩邊音量時用快速混音即可。收合標題會顯示兩邊各用什麼；兩邊都保留原唱時會立刻提醒。

8. 音色模型與訓練

程式不附任何音色模型。可以匯入你有權使用的 RVC 模型，或用自己的聲音訓練一個。

匯入模型

  1. 在 AI 翻唱 →「音色模型」→「從資料夾匯入」，輸入裝了多個模型資料夾的資料夾，例如 D:\voice-models，按 匯入（複製）。每個含 .pth 的模型資料夾都會連同 .index、說明檔、保留的中間版本一起複製過來，來源不會被改動。
  2. 也可以只給一個模型資料夾或一個 .pth 檔；「上傳模型檔」可以上傳 .pth 和選用的 .index。

模型名稱限英文、數字與 _ . -。名稱含其他字元的資料夾會被略過，請單獨匯入並自己輸入名稱。

收斂曲線與中間版本 顯示模型的訓練過程：每一輪的 mel loss 和 5 輪平均、格線數值、滑鼠指到的數值，以及判讀（還在下降／已走平／最近回升，建議比較較早的版本）。下方列出保留的中間版本和大小：用這版轉換 會在模型清單選好它，🗑 刪除（最終版會保留）。訓練中曲線會即時更新。

訓練音色模型

  1. 輸入模型名稱（預設 My_Voice_Ver1），加入語料（上傳檔案，或輸入這台電腦上的資料夾／檔案，每行一個），或按 ⚡ 帶入當前分軌人聲。乾淨的清唱或說話、合計約 10 分鐘以上效果最好。只用你自己的聲音，或已取得本人同意的聲音。
  2. 預設：100 輪（有 30／100／200 按鈕）、批次 8、每 10 輪存一版、40 kHz。
  3. 特徵模型：預設 contentvec（通用）。另一個選項是 chinese-hubert-base，用中文語料訓練的特徵模型（第一次用會先下載，約 361 MB）。模型會記住訓練時用哪一個，轉換時自動沿用，所以換特徵模型要重新訓練。不是 contentvec 的模型，在清單和選單上會標示，例如「中文特徵」。
  4. 按 🚀 開始訓練。六個步驟會自動完成：匯入、語料切片、特徵提取（RMVPE＋選的特徵模型）、訓練、建索引、安裝。儀表會顯示目前步驟、狀態燈，以及輪數、步數、最佳 loss、進度四張卡；日誌 顯示訓練輸出。
  5. 完成後模型出現在清單，附中間版本（每隔「每幾輪存一版」存一個，最多保留最後 4 個；最後一輪就是最終版）和收斂曲線；訓練暫存資料夾會自動刪除。

⏹ 中止訓練 會停止訓練，模型不會安裝。🧹 清理訓練暫存 刪除中止的訓練留下的檔案，並顯示各磁碟剩餘空間。訓練使用顯示卡，期間其他顯示卡工作會排隊等它結束。新訓練好或新匯入的模型會自動被選上。

9. MV

MV 頁有兩個分頁。

快速 MV

直接用音檔出片，不需要歌詞和照片。有兩種畫面：

  • 卡片（預設）：深色底、「COVER SESSION」、標題、「翻唱｜演唱者」，下方是跟著音樂跳動的頻譜線條（30 fps）。
  • 錄音室：漸層背景、標題、副標、版權列、右上角徽章、中間一張唱片，底部是頻譜柱（60 fps）。副標、徽章、版權列會依所選音檔（聲音模型、變調、Key）自動帶入，可以修改；副標或版權列留空就不顯示那一行。

兩種都可以選 1080p 或 720p（較快、檔案較小）。頁面會記住你選的樣式和畫質。

歌詞字幕（錄音室樣式，選填）：貼上歌詞（一行一句，或含 [mm:ss.xx] 的 LRC），按 🎙️ 自動對時間。LRC 的時間直接使用；一般歌詞由 Whisper 對到演唱位置，它只會聽一次這首歌分離後的人聲（翻唱版本和唱錄的時間跟原曲一樣，所以會先帶入原曲的時間軸）。平均分配 不用 Whisper，直接平均排好。之後逐句微調：▶ 試聽此句、−0.5／+0.5 前後移、📍 起點設為播放器目前秒數，時間和文字可以直接改，🗑 刪除，➕ 在播放位置新增一句。每個音檔的歌詞各自保存，輸出時以白字加外框燒在頻譜上方。

  1. 在翻唱版本或唱錄錄音上按 快速 MV；或打開 快速 MV 分頁，選歌和音源（原曲、翻唱版本或唱錄錄音）。
  2. 確認 標題 和 演唱者（會自動帶入「設定」裡的翻唱者名稱），按 產生快速 MV。有 NVIDIA 顯示卡時，四分鐘的歌大約一分鐘。
  3. 下方清單可以播放、下載（MP4）、在檔案總管開啟（📂）或刪除這首歌的快速 MV。「全部歌曲」會列出每首歌的快速 MV，可以搜尋、全選、刪除勾選、全部刪除。影片跟著歌曲存放，歌曲庫的「儲存空間」算在 MV 那一類。

完整 MV

用照片和歌詞做的歌詞 MV。每個專案屬於一首歌；可以從歌曲庫（製作 MV）、從一次錄音或從一個翻唱版本打開。

  1. 建立專案：選歌、專案名稱、標題與製作群。名牌卡上的翻唱者與工作室名稱來自 設定。
  2. 音檔：這首歌的原曲、一次唱錄、一個翻唱版本，或上傳的檔案（任何格式；瀏覽器不能播的會轉成 FLAC）。如果選的音檔之後被刪了（例如它的翻唱版本），頁面會說明。
  3. 照片：每個場景一張（批次上傳會依序填入空格），最多 99 張。要換順序，把照片拖到別張卡片上：照片移到那個位置，中間的照片往旁邊讓一格（◀ ／ ▶ 是跟隔壁對調）。卡片上的 ＋ 插入照片 可一次選多張照片（或把照片拖到按鈕上），選幾張就在這張前面插幾張卡片；＋ 空白 插一張空白卡。歌詞和時間留在原本的位置。
  4. 歌詞：貼上（或按 📋 貼上剪貼簿）含 [Scene 01] 標記的歌詞，按 Whisper 對齊。Whisper 會聽分離後的人聲（來自這首歌的分軌快取）替每一句定時間；之後可以調整句子、間奏與卡拉 OK 時間。
  5. 預覽 單一畫面，再 渲染：1080p 60fps MP4，有卡拉 OK 變色。渲染是顯示卡工作；新的 MV 完成前，舊的會保留。完成後會自動抽檢畫面。

📂 開啟資料夾 會在檔案總管顯示做好的 MV。📤 匯入專案 可以讀匯出的專案 JSON：JSON 裡記錄的照片、Whisper 結果、做好的 MV，以及歌曲庫以外的音檔，都會複製進專案。這首歌已經有同名專案時，會先問你要覆蓋還是兩個都留。

MV 畫面不會出現「AI」字樣：製作群使用設定裡的翻唱者名稱。

10. 工作佇列

工作佇列 列出所有工作、進度與經過時間。顯示卡工作（分離、轉換、Whisper、訓練）一次跑一個，其他的顯示排隊順位。完整 MV 渲染有自己的通道，長時間渲染不會卡住翻唱。一般工作（匯入、升降 Key、快速混音、快速 MV）可以同時跑。取消 會停止工作和它的輔助程式。日誌 顯示工作的輸出（依內容上色、自動捲到底、可複製與清空），執行中也能看。翻唱的進度和日誌會寫出正在轉的是哪一條，例如「1/2 主唱」「2/2 和聲」「✔ 已轉換和聲（35 秒）」。分離套件一些看起來像警告、其實無害的訊息（例如 ONNX Runtime 沒有 CUDA；我們的分離模型走 PyTorch 的 CUDA）不會顯示。

11. 設定

  • 歌曲庫位置：歌曲存放的資料夾（預設是 SIGN2MV 資料夾裡的 library）。選擇資料夾… 會開資料夾視窗。必須是完整路徑、不能是磁碟根目錄或程式資料夾、要能寫入；有工作在跑時不能改。
  • 翻唱者名稱與工作室名稱：顯示在 MV 名牌卡上。
  • 🎛️ 外觀（最上方那一列）：切換配色，控台 → 經典（綠色）→ 白天（亮色）。只改外觀，功能不變；唱錄和完整 MV 頁面維持它們原本的樣子。會記住你的選擇。

12. 檔案存放位置

一首歌用到的東西只有三種：

  • 原曲（source）：歌曲在就一直保留。
  • 暫存：分軌（stems，每種分離設定一份）、升降 Key（keys，每一軌每個 Key 一份）、唱錄的準備資料、翻唱暫存。所有工作區共用：誰先需要誰做，其他直接沿用。刪掉暫存不會讓任何東西壞掉，要用時會自動重新產生。
  • 你的作品：唱錄錄音、AI 翻唱版本、MV 專案與影片。刪了就沒了。錄音和翻唱版本可以當 MV 的音源。

翻唱的「變調」只改 AI 轉出來的人聲，結果放在翻唱暫存；「Key」（歌曲庫、唱錄、AI 翻唱都有）才會用到共用的升降 Key 檔。

資料夾（在 SIGN2MV 裡）內容
library\songs\<歌曲>\source（原曲）、stems、keys、sing、renders（當 MV 音檔用的錄音與翻唱版本）、cover（翻唱版本與快取）、mv（MV 專案）
library\Finished\每首歌的成品捷徑（見「成品資料夾」）；只是捷徑，刪掉不影響作品
library\recordings\所有歌曲的唱錄錄音（每筆一個資料夾：人聲、混音、設定）
models\AI 模型；models\voices＝你的 RVC 音色模型
runtime\Python 環境、Applio、ffmpeg、快取、暫存檔、訓練暫存
config\、logs\設定、記錄檔

要移除時，先關閉 SIGN2MV 再刪除整個資料夾（想保留的話先複製 library 和 models\voices）。

13. 疑難排解與回報問題

雙擊 install.bat／start.bat 時跳出「Windows 已保護您的電腦」按「其他資訊」→「仍要執行」。下次解壓縮新版前，可以先在 ZIP 的「內容」勾「解除封鎖」（見第 2 章步驟 3）。
「無法連到伺服器」主控台視窗被關掉了，再執行一次 start.bat。
頁面要求重新載入或重新啟動按 F5；或按「全部關閉」後再執行 start.bat。
缺少模型／元件再執行一次 install.bat；首頁會列出檢查結果。
音色轉換元件未安裝安裝的 Applio 部分沒有完成，再執行一次 install.bat。
升降 Key 失敗ffmpeg 沒有 Rubber Band，再執行一次 install.bat。
工作很慢到 工作佇列 看看是不是有別的顯示卡工作（例如訓練）在跑。
MV 很慢、用 CPU 編碼MV 狀態或快速 MV 清單會寫出顯示卡編碼失敗的原因（也存在 MV 旁的 encoder_errors.log）。NVIDIA 要驅動 570 版以上；更新驅動後不用重裝。
唱錄的分數一直很低先確認「音域比對」是允許高／低八度（跟原唱不同音域時），再用「重新評分」試幾個評分延遲。也可以按「🧪 測試原唱分數」確認這首歌的基準正常。
錄音時顯示「本機收音資料中斷」或「本段收音中斷」收音已停止，錄到的部分有保留。重新開啟收音（分段錄音直接再按 錄這一段）。常發生時請回報（見下方），收音記錄在 logs\native-capture.jsonl。
全部關閉後黑色視窗沒有消失直接按視窗右上角的 X 關掉，不會壞資料（工作已經停了）。
音色的 index 好像沒有作用SIGN2MV 資料夾的路徑請用英文（例如 D:\SIGN2MV）：index 元件無法開啟含中文字的路徑。

伺服器的詳細記錄在 logs\server.log，安裝記錄在 logs\install.log。

回報問題

到 GitHub Issues 開一個新 issue，寫下：

  • 做了什麼、預期看到什麼、實際看到什麼（畫面上的錯誤訊息照抄或截圖）。
  • 發生的時間，Windows 版本，顯示卡型號。
  • 相關記錄檔的片段：logs\server.log、安裝問題附 logs\install.log、收音問題附 logs\native-capture.jsonl。貼上前請看一下，裡面不要有你不想公開的檔名或路徑。
